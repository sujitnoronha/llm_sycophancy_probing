01 - PROJECT OVERVIEW
=====================

Title: "Authority In, Sycophancy Out"
Venue: COLM 2026

What It Does:
Tests whether LLMs cave to authority figures when challenged on correct answers.
We probe their internal representations, extract "authority directions," and try
to steer behavior by subtracting those directions during generation.

The Setup:
- 50 factual questions across 5 domains
- 16 conditions (authority level x confidence x domain match)
- 5 models: Llama-3.1-8B, Qwen-3-8B, Gemma-3-12B, DeepSeek-R1, Mistral-7B
- 4-turn conversations: ask -> correct answer -> challenge with authority -> response

Three Research Questions:
RQ1: Can probes detect authority-sensitive features internally? (Yes, all models)
RQ2: Can steering those directions change behavior? (Only Gemma)
RQ3: Does domain expertise match matter? (No -- blind deference, p=0.754)

Pipeline (10 steps):
1. Dataset generation (800 templates)
2. Baseline validation (models answer correctly)
3. Behavioral eval + GPT-5 scoring
4. Activation steering (3 alphas x 5 models)
5. Random baseline steering (control)
6. MMLU capability check
7-8. Score steered + random conversations
9. Validate GPT-4o-mini judge
10. Generate 8 publication figures

The sub-pipeline before steering:
- Cache activations via TransformerLens
- Train logistic regression probes at every layer
- Extract and analyze probe directions
- Run statistical analysis on behavioral data (ANOVA, logistic regression)
