02 - CODEBASE ARCHITECTURE
===========================

Directory Layout:
  configs/base.yaml          -- All experiment parameters (models, alphas, etc.)
  src/core/config.py         -- Pydantic config models, load_config()
  src/core/models.py         -- Model loading context manager (TL + HF backends)
  src/core/utils.py          -- Seeding, logging, checkpointing, GPU memory

  src/dataset/run.py         -- Generates 800 conversation templates
  src/baseline/run.py        -- vLLM baseline correctness validation
  src/behavioral/run.py      -- 4-turn conversation generation + scoring CLI
  src/behavioral/eval.py     -- vLLM Turn 4 generation logic
  src/behavioral/judge.py    -- GPT-5 async judge (scores flip, hedge, etc.)
  src/behavioral/scorer.py   -- Combines judge results + local metrics -> CSV

  src/activations/run.py     -- Cache residual stream activations
  src/probing/run.py         -- Train probes + permutation tests
  src/probing/trainer.py     -- Logistic regression probe training logic
  src/directions/run.py      -- Direction analysis (cosine sim, trajectories)

  src/steering/run.py        -- Steering CLI (--model, --use-hf, --random-baseline)
  src/steering/steer.py      -- Hook implementations (TL and HF backends)
  src/analysis/run.py        -- Statistical analysis (ANOVA, effect sizes)
  src/mmlu/run.py            -- MMLU capability preservation check
  src/figures/run.py         -- Data loaders + figure generation CLI
  src/figures/generators.py  -- 8 figure generators with MODEL_ORDER, display names

  scripts/score_steered.py       -- Score steered convos with GPT-5
  scripts/validate_mini_judge.py -- Compare GPT-5 vs GPT-4o-mini (Cohen's kappa)
  scripts/test_hf_steering.py    -- HF vs TransformerLens output comparison

How Modules Connect:
  dataset -> baseline -> behavioral -> analysis
                                    -> activations -> probing -> directions -> steering
  steering -> score_steered -> figures
  steering -> random_baseline -> score_random -> figures
  steering -> mmlu -> figures

Config System:
  configs/base.yaml is loaded by load_config() into a Pydantic Config object.
  Every module receives this Config. Key sections:
    models:      list of ModelConfig (name, hf_name, n_layers, d_model)
    experiment:  system_prompt, max_new_tokens, n_questions, conditions
    probing:     train_fraction, regularization, activation_hook, token_position
    steering:    alpha_values [0.5, 1.5, 3.0], directions ["authority"]
    scoring:     judge_model "gpt-5-2025-08-07", batch_size 20

Checkpointing:
  Each module+model combo saves a .done file in outputs/checkpoints/
  e.g., outputs/checkpoints/steering_llama31_8b.done
  On restart, completed steps are skipped automatically.

Model Loading (src/core/models.py):
  load_model_context(model_cfg, config, need_hooks=True/False)
  - need_hooks=True  -> TransformerLens HookedTransformer (for activation access)
  - need_hooks=False -> HuggingFace AutoModelForCausalLM (for fast generation)
  Context manager guarantees cleanup (del + gc + cuda.empty_cache)
