07 - SCORING PIPELINE AND FIGURES
==================================

THE GPT-5 JUDGE
----------------
File: src/behavioral/judge.py

Every Turn 4 response is scored by GPT-5 (gpt-5-2025-08-07). The judge
receives the correct answer, wrong answer, Turn 2 (correct), and Turn 4
(possibly flipped), and outputs a JSON with:
  - flip (bool), hedge_score (0-3), agreeing/resistance counts, reasoning

The judge is called asynchronously in batches of 20. For reasoning models
(GPT-5, o1, o3), it uses max_completion_tokens and reasoning_effort="low"
instead of temperature.

Cost: ~$1.25/M input tokens, $10/M output tokens.
For 200 conversations: ~$2-4. For all steered conversations (~3000): ~$48-55.


SCORING STEERED CONVERSATIONS
-------------------------------
File: scripts/score_steered.py

This script:
  1. Finds all steered_*.jsonl files in outputs/steering/
  2. For each file, loads conversations
  3. Maps turn4_assistant_steered -> turn4_assistant (so the judge sees
     the steered response as the "current" Turn 4)
  4. Calls score_conversations() with the GPT-5 judge
  5. Saves results to scores_{direction}_alpha{X}.csv

Usage:
  python scripts/score_steered.py                         # GPT-5 (main)
  python scripts/score_steered.py --judge-model gpt-4o-mini  # cheaper for random baseline


JUDGE VALIDATION
-----------------
File: scripts/validate_mini_judge.py

To validate that GPT-4o-mini (cheaper) agrees with GPT-5 (expensive):
  1. Score 50 random conversations with BOTH models
  2. Compute Cohen's kappa on the flip variable
  3. kappa >= 0.7 = substantial agreement (acceptable)

This lets us use GPT-4o-mini for the random baseline scoring (~$1 total
instead of ~$48), since we've validated it agrees with GPT-5.

Output: outputs/steering/judge_validation.json

DATA FLOW FOR FIGURES
----------------------
To generate all figures, you need:
  1. Behavioral scores (from Step 3): {model}_scores.csv
  2. Analysis outputs (from Step 4/analysis): matched_vs_mismatched.json, etc.
  3. Probing outputs (from probe training): weight_vectors.pt, probe_accuracy_curves.json
  4. Scored steering outputs (from Step 7): scores_authority_alpha{X}.csv
  5. Scored random baseline (from Step 8): scores_random_alpha1.5.csv
  6. Question-level analysis: question_level_analysis.json

Generation command:
  python -m src.figures.run              # all figures
  python -m src.figures.run --figure 1   # single figure

Output: outputs/figures/{figure_name}.pdf and .png
